PURPOSE

Run the page content readiness gate before any schema draft is built. This prompt confirms that the target page has enough confirmed, Phase 0-anchored content to support the allowed schema modules. If the page fails the readiness gate, no draft is built.

This prompt runs after Prompt 00 (intake) and before Prompt 01 (draft).

No schema is generated by this prompt. No JSON-LD is produced.

---

OPERATOR INSTRUCTION

Paste this prompt after Prompt 00 gates are confirmed. Provide the page content evidence (page copy, confirmed fields, Phase 0 cross-references) in the input. Do not proceed to Prompt 01 until this gate passes.
