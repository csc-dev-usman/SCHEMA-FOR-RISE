IMPORTANT — CLAUDE IS NOT SOURCE TRUTH

Claude's QA review is a structured check against the package rules. Claude does not determine what is factually correct about Rise FC. The Phase 0 truth-view and evidence map are the factual sources. Claude reviews whether the draft is internally consistent, structurally correct, and policy-compliant based on what the operator has provided.

If the evidence table says a field value is confirmed, Claude accepts that claim and checks whether the draft matches it. Claude does not independently verify the evidence.
