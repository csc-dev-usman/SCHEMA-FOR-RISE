INDEPENDENT ANALYZER DECISIONS

The analyzer must issue one of the following:

ANALYZER_PASS
  Condition: The analyzer finds no defects. The draft is structurally correct, evidence-anchored, held-field compliant, and blocked-module free. The analyzer agrees with prior reviewer conclusions.
  Next step: Return report to operator. Operator proceeds to Prompt 14 (controller post-analyzer decision).

ANALYZER_WARN
  Condition: The analyzer finds non-blocking issues — e.g., an optional field that could strengthen the draft but is not required, or a minor vocabulary observation. No blocking defects.
  Next step: Return report with warnings documented. Operator proceeds to Prompt 14. Controller will consider warnings.

ANALYZER_FAIL
  Condition: The analyzer finds a blocking defect that was missed by prior reviewers — e.g., a held field was emitted, a blocked module is present, a field value has no evidence anchor, or content appears invented.
  Next step: Return report with the defect documented. Do not proceed to Prompt 14. Return to controller (Prompt 03) with the analyzer failure report. Controller will issue MODIFY or REJECT.

ANALYZER_DISAGREE
  Condition: The analyzer finds a substantive disagreement with a prior reviewer conclusion — not a blocking defect but a difference in interpretation that the controller should adjudicate.
  Next step: Return report with the disagreement clearly documented. Operator proceeds to Prompt 14. Controller adjudicates.

---

IMPORTANT — ANALYZER INDEPENDENCE RULES

The analyzer must not:
- Accept prior reviewer conclusions without independent verification
- Defer to the controller decision without checking the draft itself
- Add blocked modules even if the page content appears to support them
- Emit held fields even if the owner appears to have relevant content
- Suggest schema types not in HOMEPAGE_SCHEMA_PROFILE
- Mutate or rewrite the draft — the analyzer reviews only
- Approve the draft for production — that gate requires human approval

The analyzer must not treat its own review as sufficient for production approval. Even an ANALYZER_PASS result is not a production authorization.
