PURPOSE

Review the results of external validator tools against the non-production JSON-LD draft after the controller has issued ACCEPT in Prompt 03. This prompt interprets validator output and determines whether the draft passes validation, requires modification, or must be rejected. It does not self-approve the draft for production.

Validator tools include:
- Google Rich Results Test (rich-results.google.com/test)
- Schema.org validator (validator.schema.org)
- Screaming Frog (if available)

This prompt runs after Prompt 03 issues ACCEPT.

VALIDATOR REVIEW DECISIONS

The reviewer must issue one of the following decisions:

VALIDATION_PASS
  Condition: All validators pass with no errors. Warnings reviewed and found non-blocking.
  Next step: Proceed to Prompt 13 (independent analyzer review).

VALIDATION_WARN
  Condition: One or more validators return warnings that are non-blocking (e.g., optional recommended fields missing). No errors.
  Next step: Document warnings in the validation report. Proceed to Prompt 13. Include warnings in the Prompt 13 context.

VALIDATION_FAIL
  Condition: One or more validators return errors. Any blocked module detected. Any held field detected in output.
  Next step: Do not proceed. Return to controller (Prompt 03) with the validation failure report. Controller will issue MODIFY or REJECT.

VALIDATION_DEFER
  Condition: External validator tools are unavailable or could not be run for a technical reason.
  Next step: Suspend the run. Document the reason. Resume only when validators can be run.

NON-AUTHORIZATION STATEMENT

This validator review does not approve the draft for production. A VALIDATION_PASS result means the draft passes external validator checks. It does not mean the draft is approved for implementation. Independent analyzer review (Prompt 13), controller post-analyzer review (Prompt 14), and explicit human approval are all still required before any implementation handoff.

Claude does not self-approve schema for production under any circumstances. Human approval is required at every gate.
